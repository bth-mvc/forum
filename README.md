# Forum, diskussioner och frågor med svar

Detta repo är till för att ha en plats där man kan diskutera och spara frågor/svar tillsammans med kodexempel för kursen.

Det finns en area för [forum diskussioner](https://github.com/bth-mvc/forum/discussions). Här finns diskussioner kopplade till kursen och de kursmoment som du skall genomföra. om du undrar något eller vill ha hjälp med en frågeställning så är ett foruminlägg en bra start.

I repot kan det förekomma exempelprogram eller kodexempel som kan hjälpa dig med övningar och uppgifter i kursen. Klona repot så får du tillgång till de kodexempel som finns.

Öppna en [issue](https://github.com/bth-mvc/forum/issues) om du har ett förbättringsförslag eller om du vill föreslå någon förändring i kursen.

Du kan också skapa en issue om du vill förslå något, eller diskutera, kring hur kursen bedrivs. Lärarteamet tar gärna emot förslag under tiden som kursen fortgår.
